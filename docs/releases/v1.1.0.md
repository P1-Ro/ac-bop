# acbop 1.1.0: in-game safety car limiter and CMRT HUD

## What's new

**Virtual safety car with a real speed limit.** Cars ahead of the driver who called it are now capped at a set speed (100 km/h by default), like a pit limiter, instead of being slowed with ballast or restrictor. The caller runs with no handicap and catches up several times faster than before.

**CMRT Essential HUD for drivers** (`CMRT_essential_hud_v1.0.13-acbop.zip` below):
- The leaderboard shows each driver's ballast and restrictor next to their name.
- During a safety car, the flag area reads VIRTUAL SAFETY CAR, held cars are shown in yellow and the caller in green.
- A new **Safety car** settings tab with a rebindable button to call one (any key or wheel button). It sends the normal `!vsc` chat command, so all the usual rules apply.

Also in this release:
- Every action in the web GUI confirms with a toast, with the server's reason when it fails.
- Fixed the safety car ending early when its caller crossed the finish line.
- Restrictor mode (no client setup) now stays within a vanilla server's 100% restrictor cap.

## ⚠️ Required on the server

The speed limit is applied by a small script that acbop serves and the server pushes to every player's game. CSP only lets a **server-provided** script control a car's throttle and brakes online, so the limiter can't be part of the HUD.

**1. Add this to `cfg/csp_extra_options.ini`** (or the CSP extra options box in Content Manager's server settings), using an address players can reach:

```ini
[SCRIPT_1]
SCRIPT = 'http://your.server.address:8770/csp/vsc.lua?car={SessionID}'
REQUIRED = 1
```

Keep `{SessionID}` exactly as written; the game fills it in. `REQUIRED = 1` stops anyone joining without the script. Use the next free number if you already have a `SCRIPT_1`.

**2. Open acbop's web port (default 8770) to players.** Only `/csp/` is reachable without the GUI password: the script itself and a read-only list of who is held plus every car's ballast and restrictor. Everything else still needs the password.

**3. Restart acbop** after updating.

> **Skipping step 1 still works, just worse.** Limiter mode is now the default. Without the script, a held car that doesn't slow down is caught after about 13 seconds and held with the restrictor at 100% instead. To go back to the previous server-only behaviour, set **How cars are held** (`vsc_mode`) to `restrictor` in the Settings tab.

New settings, all in the web GUI's Settings tab: `vsc_mode`, `vsc_speed_limit_kmh`, `vsc_limiter_tolerance_kmh`, `vsc_limiter_grace_s`.

## For drivers

Install `CMRT_essential_hud_v1.0.13-acbop.zip` like any CSP app: drop it on Content Manager, or copy its `assettocorsa` folder over the game's. It replaces CMRT Essential HUD 1.0.13.

The HUD finds acbop by itself from the server's `SCRIPT` line above. If it can't, type the address (for example `http://your.server.address:8770`) in **Settings → Safety car**, or add this to `csp_extra_options.ini`:

```ini
[ACBOP]
URL = 'http://your.server.address:8770'
```

The HUD is optional: the speed limit applies to every driver whether or not they have it installed.

## Not yet tested in-game

This release has been tested against a simulated server, and the in-game Lua against stand-ins for the game's functions under LuaJIT, the Lua engine CSP uses. It has not been run in Assetto Corsa yet. Worth checking on your first session: how the limiter feels (throttle fade, the brake, how quickly the cap comes down) and the leaderboard column spacing.
