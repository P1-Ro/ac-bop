# acbop 1.0.1

Safety car fixes. The server side is the only thing that changed: the HUD (`acbop_hud_v1.0.0.zip` below) is the same as in 1.0.0, so drivers who already have it don't need to reinstall.

## Changes

- **Only the last-placed car can call a safety car.** Anyone else gets "only the last-placed car can call it". The rule covers `!vsc`, the HUD button and the web GUI's safety car button. It is a new setting, **Last place only** (`vsc_last_place_only`), on by default.
- **Cars without the in-game limiter are caught straight away.** The limiter script now checks in with acbop, so acbop knows which games are running it. A held car whose game hasn't checked in is put on full restrictor as soon as the safety car starts, rather than running at full speed for about 13 seconds first. The events log names the cars and points at `csp_extra_options.ini`.
- **The Live tab warns you before a race.** Every car whose game isn't running the limiter shows a **no SC script** pill.
- **The limiter finds its own car more reliably.** If the game doesn't fill in `{SessionID}` in the script address, the script asks the game for its server slot instead of matching by driver name.

## ⚠️ Check your server config

If the cars ahead weren't slowed at all under a safety car in 1.0.0, the `[SCRIPT_1]` entry is probably missing from the server's `cfg/csp_extra_options.ini`. Without it, nothing in the game caps their speed, and the server's restrictor fallback is only worth about 20% of lap time. Add it, with an address players can reach:

```ini
[SCRIPT_1]
SCRIPT = 'http://your.server.address:8770/csp/vsc.lua?car={SessionID}'
REQUIRED = 1
```

Players have to rejoin to pick it up. The **no SC script** pills on the Live tab disappear once their games are running it.

## Upgrading

Pull `master` (or download this release) and restart acbop. No settings need changing.
