# acbop 1.0.0

Adaptive balance of performance for Assetto Corsa: acbop learns how quick each driver is and hands out ballast and restrictor so a mixed-ability group races together. It runs alongside your acServer as a UDP plugin, with a web GUI to watch and override everything.

## Highlights

- **Handicaps learned from lap times**, per driver, track and car. A driver who has never run a track still gets a sensible number from everything else they've driven.
- **Virtual safety car with a real speed limit.** A driver who's been dropped types `!vsc` (or presses a button in the acbop HUD). Once per race, the cars ahead are capped at 100 km/h by default while the caller runs with no handicap. It ends when they've caught up.
- **acbop HUD for drivers** (`acbop_hud_v1.0.0.zip` below): a leaderboard with every driver's ballast and restrictor, a VIRTUAL SAFETY CAR flag with held cars and the caller coloured, and a rebindable safety car button. The leaderboard is CMRT Essential HUD's (by CMRT Group), cut down to just that. It installs as its own app, so it doesn't replace a driver's CMRT.
- **Web GUI** to watch the grid, run and end safety cars, pin handicaps by hand, and inspect every lap and the model. Every action confirms with a toast.

## ⚠️ Setting up the server

**1. Run acbop next to acServer** and point the two at each other. See [Install](https://github.com/P1-Ro/ac-bop#install) in the README.

**2. Add the in-game limiter to `cfg/csp_extra_options.ini`** (or the CSP extra options box in Content Manager's server settings), using an address players can reach:

```ini
[SCRIPT_1]
SCRIPT = 'http://your.server.address:8770/csp/vsc.lua?car={SessionID}'
REQUIRED = 1
```

CSP only lets a server-provided script control a car's throttle and brakes online, so this is what holds cars at the speed limit. Keep `{SessionID}` exactly as written; the game fills it in. `REQUIRED = 1` stops anyone joining without the script. Use the next free number if you already have a `SCRIPT_1`.

**3. Open acbop's web port (default 8770) to players.** Only `/csp/` is reachable without the GUI password: the script itself and a read-only list of who is held plus every car's ballast and restrictor. Set a strong `web_password` for everything else.

> **Skipping step 2 still works, just worse.** A held car that doesn't slow down is caught after about 13 seconds and held with the restrictor at 100% instead. To use that server-only behaviour from the start, set **How cars are held** (`vsc_mode`) to `restrictor` in the Settings tab.

## For drivers

Install `acbop_hud_v1.0.0.zip` like any CSP app: drop it on Content Manager, or copy its `assettocorsa` folder over the game's. Then enable the **acbop leaderboard** window in-game. Settings, including the safety car button binding, are in the **acbop settings** window.

The HUD finds acbop by itself from the server's `SCRIPT` line above. If it can't, type the address (for example `http://your.server.address:8770`) in **acbop settings → Safety car**.

The HUD is optional: the speed limit applies to every driver whether or not they have it installed.

## Not yet tested in-game

The in-game limiter and the HUD have been tested under LuaJIT, the Lua engine CSP uses, with the game's functions stood in, including a headless run of the whole HUD through a faked race. The server side is tested against a simulated AC server. Neither has been run in Assetto Corsa yet. Worth checking on your first session: how the limiter feels (throttle fade, the brake, how quickly the cap comes down), and the leaderboard's look and spacing.
