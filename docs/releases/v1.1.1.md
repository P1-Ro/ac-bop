# acbop 1.1.1: acbop HUD, cut down to the leaderboard

## What's changed

The driver app is now **acbop HUD** (`acbop_hud_v1.1.1.zip` below), a small app holding just the leaderboard from CMRT Essential HUD plus acbop's additions. It replaces the full modified CMRT Essential HUD that shipped with 1.1.0.

- **Leaderboard:** each driver's ballast and restrictor next to their name. During a virtual safety car, held cars are shown in yellow, the caller in green, and the flag area reads VIRTUAL SAFETY CAR.
- **Rebindable safety car button:** in **acbop settings → Safety car**, click the box and press any key or wheel button. It sends the normal `!vsc` chat command, so all the usual rules apply.
- **Everything else from CMRT is gone:** the other apps (gearbox, tyres, map, radar, pedals, sectors, deltabar, clocks), the logos and intro animations, and the fonts and images the leaderboard doesn't use.
- **Installed as its own app, `acbop-HUD`:** it no longer overwrites a driver's CMRT Essential HUD, so both can be installed side by side.

Nothing changed on the server side since 1.1.0.

## Required on the server (unchanged from 1.1.0)

If you already set this up for 1.1.0, there's nothing to do.

**1. Add this to `cfg/csp_extra_options.ini`** (or the CSP extra options box in Content Manager's server settings), using an address players can reach:

```ini
[SCRIPT_1]
SCRIPT = 'http://your.server.address:8770/csp/vsc.lua?car={SessionID}'
REQUIRED = 1
```

Keep `{SessionID}` exactly as written; the game fills it in. `REQUIRED = 1` stops anyone joining without the script. Use the next free number if you already have a `SCRIPT_1`.

**2. Open acbop's web port (default 8770) to players.** Only `/csp/` is reachable without the GUI password: the script itself and a read-only list of who is held plus every car's ballast and restrictor.

**3. Restart acbop** after updating.

Without step 1 the safety car still works, but held cars that don't slow down are held with the restrictor at 100% after about 13 seconds instead of being speed-limited. To use that server-only behaviour from the start, set **How cars are held** (`vsc_mode`) to `restrictor` in the Settings tab.

## For drivers

Install `acbop_hud_v1.1.1.zip` like any CSP app: drop it on Content Manager, or copy its `assettocorsa` folder over the game's. Then enable the **acbop leaderboard** window in-game. Settings are in the **acbop settings** window.

The HUD finds acbop by itself from the server's `SCRIPT` line above. If it can't, type the address (for example `http://your.server.address:8770`) in **acbop settings → Safety car**.

**If you installed the 1.1.0 zip:** it replaced your `CMRT-Essential-HUD` app with a modified copy, and by mistake also put an unused file in that folder (`lupa-2.8-…whl`, a Python package the game ignores). Delete the `assettocorsa/apps/lua/CMRT-Essential-HUD` folder, then reinstall CMRT Essential HUD from CMRT if you use it.

The HUD is optional: the speed limit applies to every driver whether or not they have it installed.

## Not yet tested in-game

The HUD and the in-game limiter have been tested under LuaJIT, the Lua engine CSP uses, with the game's functions stood in, including a headless run of the whole HUD through a faked race. They have not been run in Assetto Corsa yet. Worth checking on your first session: the leaderboard's look and spacing, and how the limiter feels.
