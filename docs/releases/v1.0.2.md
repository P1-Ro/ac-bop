# acbop 1.0.2

Safety car limiter fixes. The server side is the only thing that changed: the HUD (`acbop_hud_v1.0.0.zip` below) is the same as in 1.0.0, so drivers who already have it don't need to reinstall.

## ⚠️ If the limiter did nothing on your server

Vanilla acServer never reads `cfg/csp_extra_options.ini`. CSP only finds extra options packed at the end of the server's **welcome message**, and Content Manager puts them there only when it starts the server itself. A server started any other way (a Linux host, a dedicated box, a deploy script, a server manager) never sent the `[SCRIPT_...]` entry, so no player's game ever ran the limiter. The earlier README and release notes pointed at the `.ini`, which was wrong.

To fix it, from the acServer folder, after writing the entry to `cfg/csp_extra_options.ini`:

```bash
python3 /path/to/acbop/tools/csp_welcome.py           # pack it into the welcome message
python3 /path/to/acbop/tools/csp_welcome.py --check   # show what players will get
```

Then restart acServer. Players have to rejoin to pick it up, and the **no SC script** pills on the Live tab disappear once their games are running it. Re-run the tool whenever a deploy replaces `cfg/`.

## Changes

- **New `tools/csp_welcome.py`.** Packs the CSP extra options into the welcome message the same way Content Manager does, keeping any visible welcome text and replacing an earlier block rather than adding a second one. `--check` prints what the server is sending now and warns if the limiter's entry is missing. If `WELCOME_MESSAGE` points at a Windows path (as a Content Manager package can), it writes `cfg/welcome.txt` instead and tells you to point the server at it.
- **The limiter script reports its own errors.** An error in the in-game script used to stop it silently. It now catches the error, keeps running, and reports it to acbop with its next poll, so it shows in the events log as "limiter script error in …'s game".
- **The limiter shows its state in CSP's Lua Debug app:** its car slot, its polls to acbop, whether a safety car is running and whether this car is held.
- **README:** where the extra options really go, how to test on your own PC, and a step-by-step for when the limiter does nothing.

## Upgrading

Pull `master` (or download this release) and restart acbop. No settings need changing. Then fix the welcome message as above if your server isn't started from Content Manager.
